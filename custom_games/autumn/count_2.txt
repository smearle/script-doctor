title count_2 (AutumnBench port)
author ported from AutumnBench count_2.sexp

(
  Port of AutumnBench count_2.sexp (GRID_SIZE 100).
  A single Blob starts at (50,50). Hidden velocities xVel and yVel in {-2..2}.
  Every frame the blob moves by sign(prev xVel) horizontally and sign(prev yVel) vertically.
  When xActive=True (default): left/right adjust xVel (clamped to [-2,+2]).
  When xActive=False (after click): up adjusts yVel down to -2; down is broken in Autumn (no effect).
  Click toggles xActive -- PS has no targeted click, so xActive stays True for arrows-only play.
  yVel stays 0 for arrows-only sessions (up/down have no effect when xActive=True).
  Velocity stored as invisible markers XN2/XN1/XP1/XP2 (absence = vel 0) on hidden Player.
  Rules: move blob by OLD velocity FIRST (prev-lag), THEN update velocity from input.
  Off-grid fix: WillMove marker detects when Blob is blocked at the level boundary (meaning
  Autumn would have moved it off-grid); the blocked Blob is destroyed in a LATE rule so that
  PS matches Autumn (which filters out-of-bounds objects from its render).
)

======
RULES
======

(=== STEP 1: Move blob by CURRENT (prev-frame) velocity markers ===)
(x-axis: XNx markers => move left, XPx markers => move right)
(Also stamp WillMove on the blob's cell; if movement is blocked by the level boundary,
 the LATE rule will detect blob+WillMove co-located and destroy the blob.)
[ XN1 ][ Blob ] -> [ XN1 ][ left Blob WillMove ]
[ XN2 ][ Blob ] -> [ XN2 ][ left Blob WillMove ]
[ XP1 ][ Blob ] -> [ XP1 ][ right Blob WillMove ]
[ XP2 ][ Blob ] -> [ XP2 ][ right Blob WillMove ]

(y-axis: YNx markers => move up (y decreases), no YP because down is broken in Autumn)
[ YN1 ][ Blob ] -> [ YN1 ][ up Blob WillMove ]
[ YN2 ][ Blob ] -> [ YN2 ][ up Blob WillMove ]

(=== STEP 2: Update xVel from left/right input ===)
(right pressed: xVel += 1, clamped at +2)
[ right Player XP2 ] -> [ Player XP2 ]
[ right Player XP1 ] -> [ Player XP2 ]
[ right Player no XN1 no XN2 no XP1 no XP2 ] -> [ Player XP1 ]
[ right Player XN1 ] -> [ Player ]
[ right Player XN2 ] -> [ Player XN1 ]

(left pressed: xVel -= 1, clamped at -2)
[ left Player XN2 ] -> [ Player XN2 ]
[ left Player XN1 ] -> [ Player XN2 ]
[ left Player no XN1 no XN2 no XP1 no XP2 ] -> [ Player XN1 ]
[ left Player XP1 ] -> [ Player ]
[ left Player XP2 ] -> [ Player XP1 ]

(stop Player from actually moving)
[ moving Player ] -> [ Player ]

(=== STEP 3: Update yVel from up/down input (only when xActive=False, deferred) ===)
(In arrows-only play, xActive stays True so up/down do nothing -- which is correct.)

(=== LATE: destroy blob blocked at level boundary (off-grid exit in Autumn) ===)
late [ Blob WillMove ] -> [ ]
(clean up any WillMove left at the blob's old position after a successful move)
late [ WillMove ] -> [ ]
