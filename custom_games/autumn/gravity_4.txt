title gravity_4 (AutumnBench port)
author ported from AutumnBench gravity_4.sexp

(
  Port of AutumnBench gravity_4.sexp (GRID_SIZE=100).

  Autumn render_all keys: buttons, blobs.

  8 buttons at edge positions control gravity for all blobs:
    red        @ (4,0)   -> gravity ul (-1,-2)
    gold       @ (8,0)   -> gravity uu (0,-2)
    darkorange @ (12,0)  -> gravity ur (+1,-2)
    lightgreen @ (99,4)  -> gravity ru (+2,-1)
    green      @ (99,8)  -> gravity rr (+2,0)  [default]
    lightseagreen @ (99,12) -> gravity rd (+2,+1)
    lightblue  @ (4,99)  -> gravity dl (-1,+2)
    blue       @ (8,99)  -> gravity dd (0,+2)

  Blob is 2x2. Clicking at (x,y) places cells at (x,y-1),(x,y),(x+1,y-1),(x+1,y).

  Movement uses 2-3 phase teleport each tick:
    rr (+2,0):  2x right
    dd (0,+2):  2x down
    uu (0,-2):  2x up
    ru (+2,-1): 2x right + 1x up
    rd (+2,+1): 2x right + 1x down
    ul (-1,-2): 1x left  + 2x up
    ur (+1,-2): 1x right + 2x up
    dl (-1,+2): 1x left  + 2x down

  Gravity change: clicking a button changes all blobs to the new variant.
  GravState marker lives at (0,0) permanently; Player moves freely.

  Deferred: isFreePos check (PS has no targeted click; all clicks place blobs).
  Caveat: blobs fly off grid immediately (off-grid motion, no bounds in Autumn).
  Caveat: 100x100 grid is large; PS is slow.
)

realtime_interval 0.1
