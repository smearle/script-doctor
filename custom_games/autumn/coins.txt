title coins (AutumnBench port)
author ported from AutumnBench coins.sexp

(
  Port of AutumnBench coins.sexp (GRID_SIZE=16).

  Agent (red) moves with arrow keys, starts at (7,9).
  Coins (gold) at even-x, even-y positions in rect x=[4..12], y=[2,4]:
    (4,2)(6,2)(8,2)(10,2)(12,2)(4,4)(6,4)(8,4)(10,4)(12,4).

  COIN COLLECTION - one-frame prev-semantics delay:
    Autumn uses `prev agent` to detect coin intersection, so the coin is
    collected the frame AFTER the agent first stands on it.
    Implementation: a `late` rule converts Coin->CoinPending when the Player
    stands on it at the END of the tick. The NEXT tick's regular rules remove
    CoinPending and increment the bullet count. Both Coin and CoinPending alias
    to "coins" so the harness sees the coin present on the arrival tick and
    absent on the following tick -- matching Autumn exactly.

  BULLET COUNT (numBullets):
    Tracked with a HUD strip of 10 BulletSlot/BulletSlotEmpty objects in row 17
    (outside the 16x16 comparison area). Each BulletSlot = 1 bullet available.
    Collecting a coin: CoinPending removed, one BulletSlotEmpty -> BulletSlot.
    Firing a bullet: BulletSlot -> BulletSlotEmpty, NewBullet spawned.

  BULLET MOVEMENT:
    Bullets move UP every frame (autonomous). In Autumn, bullets can go to y<0
    (off-grid). In PS, bullets clamp at y=0 -- known inherent cap, diverges only
    when a bullet would exit the top of the grid.

  BULLET SPAWN TIMING:
    In Autumn, `on true` (bullet movement) runs before the click handler, so a
    bullet spawned by clicking does NOT move up on the spawn frame. Modeled with
    NewBullet: spawned by `action`, converted to Bullet via a late rule so it
    does not participate in the regular-phase `up` movement that tick.

  OFF-GRID AGENT MOTION (inherent cap):
    In Autumn, the agent has no grid-boundary clamping and can move to x<0 or
    x>=16, disappearing from the 16x16 comparison area. PS clamps at the border.
    Diverges only when the agent actually reaches a grid edge.

  Input modality: arrows (agent movement) + action/X (fire bullet when numBullets>0).
)

( === COIN COLLECTION: remove CoinPending, increment bullet count ===
  CoinPending was created by the late rule on the PREVIOUS tick (agent stood on
  coin last tick). This regular rule fires at the START of the next tick.
  Simultaneously converts one BulletSlotEmpty to BulletSlot (numBullets+1). )
[ CoinPending ] [ BulletSlotEmpty ] -> [ ] [ BulletSlot ]

( === LATE: mark coin as pending when Player is standing on it ===
  Fires at END of tick (after movement), creating CoinPending for next tick.
  Autumn fires the collection handler using prev agent -- same 1-frame delay. )
late [ Player Coin ] -> [ Player CoinPending ]

( === LATE: activate NewBullet ===
  NewBullet converts to Bullet at end of tick, so it won't move up on spawn frame. )
