title Disease (AutumnBench port)
author ported from AutumnBench disease.sexp

(
  disease.sexp (GRID_SIZE=16).  Five particles total.
  * activeParticle  (health=false, darkgreen): starts at (2,2), moves with arrows.
  * inactiveParticles (health=true, gray): 4 static particles at (7,5),(4,3),(6,6),(3,5).

  Autumn (on ...) handlers implemented:
    on left/right/up/down : move activeParticle by +/-1 (off-grid clamped at border in PS)
    on (clicked inactiveParticles): swap – clicked inactive becomes new active; old active
        added back to inactive list.  Implemented via modal cursor + flood-fill swap.
    inactiveParticles autonomous update (infection spreading, color only – irrelevant to
        class-based harness comparison, not modelled in PS).

  Modal design (same as arc_slack):
    ARROW mode (no CMode):  arrows redirect to ActiveParticle; X enters cursor mode,
        spawning Cursor at CursorHome (0,0).
    CURSOR mode (CMode): arrows move Cursor; X clicks:
        on InactiveParticles  -> swap (flood-fill to find old active anywhere on board)
        on BackButton (row 16) -> return to arrow mode.

  SWAP MECHANIC (flood fill):
    Click places SwapSig (in InactiveP layer) on clicked cell.
    FindSig (helper layer) floods from SwapSig outward each rule-loop iteration.
    When FindSig co-occupies ActiveParticle: converts it to FoundActive.
    Late rules resolve: SwapSig -> ActiveParticle, FoundActive -> InactiveParticles,
    FindSig cleared.

  CAPS:
    Off-grid motion: Autumn lets activeParticle leave the 16x16 grid; PS clamps at border.
    Infection spreading (color changes on inactiveParticles) not modelled – class-based only.

  Eval sidecar: activeparticle / inactiveparticles matched by name (no alias needed).
  cursor_start=[0,0] (CursorHome position).
)

realtime_interval 0.1

======
RULES
======

( ===== ARROW MODE: arrows move ActiveParticle ===== )
[ left  Player no CMode ] [ ActiveParticle ] -> [ Player ] [ left  ActiveParticle ]
[ right Player no CMode ] [ ActiveParticle ] -> [ Player ] [ right ActiveParticle ]
[ up    Player no CMode ] [ ActiveParticle ] -> [ Player ] [ up    ActiveParticle ]
[ down  Player no CMode ] [ ActiveParticle ] -> [ Player ] [ down  ActiveParticle ]

( Enter cursor mode: X in arrow mode -> spawn Cursor at CursorHome )
[ action Player no CMode ] [ CursorHome no Cursor ] -> [ Player CMode ] [ CursorHome Cursor ]

( ===== CURSOR MODE: arrows move Cursor ===== )
[ left  Player CMode ] [ Cursor ] -> [ Player CMode ] [ left  Cursor ]
[ right Player CMode ] [ Cursor ] -> [ Player CMode ] [ right Cursor ]
[ up    Player CMode ] [ Cursor ] -> [ Player CMode ] [ up    Cursor ]
[ down  Player CMode ] [ Cursor ] -> [ Player CMode ] [ down  Cursor ]

( ===== X in cursor mode: click at cursor cell ===== )

( BackButton: exit cursor mode )
[ action Player CMode ] [ Cursor BackButton ] -> [ Player ] [ BackButton ]

( Click on InactiveParticle: initiate swap )
[ action Player CMode ] [ Cursor InactiveParticles ] -> [ Player CMode ] [ Cursor SwapSig ]

( ===== SWAP RESOLUTION (flood-fill) ===== )
( Start flood from the SwapSig cell )
[ SwapSig no FindSig ] -> [ SwapSig FindSig ]

( Propagate FindSig outward -- fires until entire board is covered )
[ FindSig ] [ no FindSig ] -> [ FindSig ] [ FindSig ]

( When FindSig co-occupies ActiveParticle: capture it )
[ FindSig ActiveParticle ] -> [ FindSig FoundActive ]

( LATE: resolve swap + cleanup )
late [ SwapSig ] -> [ ActiveParticle ]
late [ FoundActive ] -> [ InactiveParticles ]
late [ FindSig ] -> [ ]

( Player anchor never moves )
[ moving Player ] -> [ Player ]
