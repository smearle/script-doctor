title nim (AutumnBench port)
author ported from AutumnBench nim.sexp

(
  Port of AutumnBench nim.sexp (GRID_SIZE=17).

  The Nim game: four rows of matches (1, 3, 5, 7 matches). Player clicks to:
    - Toggle a match selected/unselected (maroon <-> brown).
    - Click the red RemoveButton for a row to remove all selected matches in that row.

  State is color-encoded: maroon=#800000 (unselected), brown=#a52a2a (selected).
  Each row uses separate object types so the harness can alias them to the correct
  Autumn render_all keys (row1_match, row2_match, etc.).

  Remove button logic: clicking RemBtnN sets an invisible RemFlagN marker. A
  global rule "[RemFlagN] [Match_N_Brown] -> [RemFlagN] [Background]" then removes
  all selected matches in that row. Finally RemFlagN is cleaned up.

  Player is the invisible cursor used for the click emulation convention.
  cursor_start is [0,0] (default). compare_color=true.
)
