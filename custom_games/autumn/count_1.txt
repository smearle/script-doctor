author ported from AutumnBench count_1.sexp

(
  Port of AutumnBench count_1.sexp (GRID_SIZE 100). Autumn render key: blobs (alias blob->blobs).
  A single Blob has a hidden horizontal velocity xVel in {-1,0,1}.
    - left/right adjust xVel (clamped); up/down do nothing while xActive (true here, no click).
    - every frame the blob moves by sign(prev xVel)  -> one-frame velocity lag.
  Hidden velocity is held as Vneg/Vpos markers on an invisible, immovable Player.
  Deferred: click toggles the active axis (x<->y).
)

RULES

[ Vneg ][ Blob ] -> [ Vneg ][ left Blob ]
[ Vpos ][ Blob ] -> [ Vpos ][ right Blob ]

(update velocity from left/right input, clamped to [-1,1])
[ left Player Vpos ] -> [ Player ]
[ left Player no Vpos no Vneg ] -> [ Player Vneg ]
[ right Player Vneg ] -> [ Player ]
[ right Player no Vpos no Vneg ] -> [ Player Vpos ]

(the velocity-holder Player never actually moves)
[ moving Player ] -> [ Player ]
