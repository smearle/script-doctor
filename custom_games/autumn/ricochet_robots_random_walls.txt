(
  Port of "ricochet_robots_random_walls". GRID_SIZE = 24.

  Mechanics:
    - 4 robots on a 24x24 grid. Arrow keys slide robot1 (= PS player) until
      blocked by a wall/border/other robot. Robots 2-4 are idle.
    - Faithful Autumn timing: a robot continues "moving" even on the tick it
      arrives adjacent to a wall; it only STOPS on the tick it TRIES to move
      into the wall and fails. New input is ignored while moving.

  Implementation:
    Robot1 states: robot1 (stopped), robot1r/l/u/d (moving), robot1xWaiting
    (just arrived next to wall, still "moving" conceptually -- matches Autumn
    prev-semantics where moving=true until the blocked attempt fires).
    JustCreated marker: set on the tick a key starts motion; used to detect
    immediate blocks (direction pressed into wall → stops same tick, like Autumn).
    NoInput marker: when robot1 transitions from Waiting, prevents new key from
    starting movement on that same tick (matches Autumn's prev(moving)=true guard).
)

======
RULES
======

(=== CONTINUOUS MOVEMENT: sliding variants move 1 cell/tick ===)
[ robot1r ] -> [ right robot1r ]
[ robot1l ] -> [ left  robot1l ]
[ robot1u ] -> [ up    robot1u ]
[ robot1d ] -> [ down  robot1d ]

(=== WAITING -> STOPPED (with NoInput to block new key on this tick) ===
 These fire first so the NoInput is in place before key-handling rules run.)
[ robot1rWaiting ] -> [ robot1 NoInput ]
[ robot1lWaiting ] -> [ robot1 NoInput ]
[ robot1uWaiting ] -> [ robot1 NoInput ]
[ robot1dWaiting ] -> [ robot1 NoInput ]

(=== KEY HANDLING: start sliding from stopped state ===
 Only fires for robot1 (stopped) when no NoInput guard is present.
 JustCreated co-occupies the creation cell so we can detect immediate blocks.)
[ right robot1 no NoInput ] -> [ right robot1r JustCreated ]
[ left  robot1 no NoInput ] -> [ left  robot1l JustCreated ]
[ up    robot1 no NoInput ] -> [ up    robot1u JustCreated ]
[ down  robot1 no NoInput ] -> [ down  robot1d JustCreated ]

(=== LATE RULES ===)

(Immediately stop when blocked on the CREATION tick -- Autumn stops same-frame
 when the first move is already against a wall. Detected by JustCreated being in
 the same cell as the blocked sliding variant.)
late right [ JustCreated robot1r | Blocker ] -> [ robot1 | Blocker ]
late left  [ JustCreated robot1l | Blocker ] -> [ robot1 | Blocker ]
late up    [ JustCreated robot1u | Blocker ] -> [ robot1 | Blocker ]
late down  [ JustCreated robot1d | Blocker ] -> [ robot1 | Blocker ]

(Transition to Waiting when the robot moved at least once before hitting the wall.
 JustCreated will be in the PREVIOUS cell (robot moved away), so `no JustCreated`
 is true in the sliding variant's NEW cell.)
late right [ robot1r no JustCreated | Blocker ] -> [ robot1rWaiting | Blocker ]
late left  [ robot1l no JustCreated | Blocker ] -> [ robot1lWaiting | Blocker ]
late up    [ robot1u no JustCreated | Blocker ] -> [ robot1uWaiting | Blocker ]
late down  [ robot1d no JustCreated | Blocker ] -> [ robot1dWaiting | Blocker ]

(Clean up orphaned JustCreated markers left behind when robot moved away.)
late [ JustCreated ] -> [ ]

(Clear NoInput at end of tick so next tick's input is unblocked.)
late [ NoInput robot1 ] -> [ robot1 ]
