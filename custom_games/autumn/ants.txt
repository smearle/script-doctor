title ants (AutumnBench port)
author ported from AutumnBench ants.sexp

(
  Port of AutumnBench ants.sexp (GRID_SIZE 16). Render keys: ants, foods.
  Two ants (gray) at (5,5) and (1,14); foods (red) start empty.

  Each frame (Autumn filter-then-move order):
    1. Food coincident with an ant is eaten BEFORE movement.
    2. Each ant moves ONE cell toward its NEAREST food, x-priority (move horizontally unless
       x-aligned with the target, else vertically). No food -> ants static.

  CLICK = action (X). Position is irrelevant (Autumn spawns at random cells), so the Player is
  an invisible fixed phantom. Each click spawns TWO foods at uniform-random UNOCCUPIED cells,
  like Autumn, via PuzzleScript's uniform `random` (not Autumn's anti-diagonal-biased RNG), so
  exact cells differ run to run but the mechanic matches.

  NEAREST-FOOD SEEK by flooding ONE marker out from the food (your suggestion):
    - Foods seed a Frontier. A startloop pushes the Frontier outward ONE ring per iteration
      (BFS wavefront); each newly reached cell records the back-direction toward the food
      (Flow*), trying HORIZONTAL before vertical -- that is exactly the x-priority unitVector.
    - Each ant then steps along the Flow at its cell, i.e. toward the nearest food.
  The flood is BFS so it picks the (Manhattan-)nearest food; this differs from Autumn's
  squared-Euclidean `closest` only when two foods are near-equidistant. Ants share one
  object/layer, so two ants cannot occupy the same cell (Autumn allows overlap).
)

======
RULES
======

( 1. EAT any food an ant sits on, before movement )
[ Ant Food ] -> [ Ant ]

( 2. seed the flood: foods are the initial frontier )
[ Food no Seen ] -> [ Food Seen Frontier ]

( 3. push the frontier out one ring per iteration; record the back-direction toward the
     food (Flow*), HORIZONTAL rules first so the recorded direction is x-priority )
startloop
  right [ Frontier | no Seen ] -> [ Frontier | Seen FlowLeft  NewFront ]
  left  [ Frontier | no Seen ] -> [ Frontier | Seen FlowRight NewFront ]
  up    [ Frontier | no Seen ] -> [ Frontier | Seen FlowDown  NewFront ]
  down  [ Frontier | no Seen ] -> [ Frontier | Seen FlowUp    NewFront ]
  [ Frontier ] -> []
  [ NewFront ] -> [ Frontier ]
endloop

( 4. each stationary ant steps along the flow at its cell = toward the nearest food )
[ FlowLeft  stationary Ant ] -> [ FlowLeft  left  Ant ]
[ FlowRight stationary Ant ] -> [ FlowRight right Ant ]
[ FlowUp    stationary Ant ] -> [ FlowUp    up    Ant ]
[ FlowDown  stationary Ant ] -> [ FlowDown  down  Ant ]

( 5. click spawns TWO foods at uniform-random unoccupied cells, after movement )
[ action Player ] -> [ Player Spawn2 ]
random [ Spawn2 ] [ Background no Food no Ant ] -> [ Spawn1 ] [ Background Food ]
random [ Spawn1 ] [ Background no Food no Ant ] -> [ ] [ Background Food ]

( phantom player never moves )
[ moving Player ] -> [ Player ]

( 6. clear the flood so it recomputes fresh next tick )
late [ Seen ] -> []
late [ Frontier ] -> []
late [ NewFront ] -> []
late [ Flow ] -> []
