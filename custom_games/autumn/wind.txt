(
  Port of AutumnBench "wind" (GRID_SIZE 17).

  Mechanics:
    - Cloud fills rows 0-1, all 17 columns (static).
    - Water falls each frame. Movement depends on wind:
        wind= 0: DOWN only
        wind=+1: RIGHT then DOWN
        wind=-1: LEFT then DOWN
    - Wind clamped to {-1, 0, +1}. left decrements, right increments.
    - Water spawns at y=2, x=2,6,10,14 when prev_time%5==2
      (ticks 3, 8, 13, ... from initial).
    - Autumn: water that leaves the 17x17 grid persists in its internal
      list when an `on` movement rule fires (overrides isWithinBounds).
      Such water can re-enter bounds when wind reverses.

  Three-step ghost tracking (handles up to 3 steps OOB):
    GhostLk at PS column 0, row y represents Autumn water at (x=-k, y).
    GhostRk at PS column 16, row y represents Autumn water at (x=17+k-1, y).
    k=1,2,3 (GhostL, GhostL2, GhostL3 / GhostR, GhostR2, GhostR3).

  Ghost lifecycle (GhostLk example):
    - Created from GhostL(k-1)+WantLeft in late phase (down = y+1).
      (GhostL itself is created from border Water+WantLeft+no HM.)
    - wind=0: moves DOWN (VM prevents cascade within a tick).
    - wind=+1: converts to GhostL(k-1)+VM at (0,y+1).
      VM prevents immediate re-conversion in the same tick; removed in late.
    - wind=-1 (WantLeft stamped): going to x=-(k+1).
      k<3: creates GhostL(k+1) one row down.
      k=3: untracked; destroy.

  Counter: SpawnPos+Tc0..Tc4. Tc2->Tc3 triggers late spawn. JT prevents cascade.
)

RULES
======

( === COUNTER ADVANCE === )
[ SpawnPos Tc2 no JT ] -> [ SpawnPos Tc3 JT ]
[ SpawnPos Tc0 no JT ] -> [ SpawnPos Tc1 JT ]
[ SpawnPos Tc1 no JT ] -> [ SpawnPos Tc2 JT ]
[ SpawnPos Tc3 no JT ] -> [ SpawnPos Tc4 JT ]
[ SpawnPos Tc4 no JT ] -> [ SpawnPos Tc0 JT ]

( === STAMP WANT-DIRECTION ON WATER AND ALL GHOST LAYERS === )
[ Wn1 ] [ Water   no WantLeft  ] -> [ Wn1 ] [ Water   WantLeft  ]
[ Wp1 ] [ Water   no WantRight ] -> [ Wp1 ] [ Water   WantRight ]
[ Wn1 ] [ GhostL  no WantLeft  ] -> [ Wn1 ] [ GhostL  WantLeft  ]
[ Wp1 ] [ GhostR  no WantRight ] -> [ Wp1 ] [ GhostR  WantRight ]
[ Wn1 ] [ GhostL2 no WantLeft  ] -> [ Wn1 ] [ GhostL2 WantLeft  ]
[ Wp1 ] [ GhostR2 no WantRight ] -> [ Wp1 ] [ GhostR2 WantRight ]
[ Wn1 ] [ GhostL3 no WantLeft  ] -> [ Wn1 ] [ GhostL3 WantLeft  ]
[ Wp1 ] [ GhostR3 no WantRight ] -> [ Wp1 ] [ GhostR3 WantRight ]

( === GHOST CONVERSIONS: deeper -> shallower layer on wind reversal === )
( GhostL3 + wind=+1 (x=-3 -> x=-2 = GhostL2) )
down [ Wp1 ] [ GhostL3 no VM | no GhostL2 ] -> [ Wp1 ] [ | GhostL2 VM ]
( Symmetric: GhostR3 + wind=-1 )
down [ Wn1 ] [ GhostR3 no VM | no GhostR2 ] -> [ Wn1 ] [ | GhostR2 VM ]
( GhostL2 + wind=+1 (x=-2 -> x=-1 = GhostL) )
down [ Wp1 ] [ GhostL2 no VM | no GhostL  ] -> [ Wp1 ] [ | GhostL  VM ]
( Symmetric: GhostR2 + wind=-1 )
down [ Wn1 ] [ GhostR2 no VM | no GhostR  ] -> [ Wn1 ] [ | GhostR  VM ]

( === GHOST-L/R CONVERSION TO REAL WATER: x=-1 + wind=+1 -> x=0 === )
( no VM: blocks freshly-created GhostL (from GhostL2 conversion) from     )
( converting to Water in the same tick; VM is cleaned in late.             )
[ Wp1 ] [ GhostL no HM no Water no VM ] -> [ Wp1 ] [ Water HM ]
[ Wn1 ] [ GhostR no HM no Water no VM ] -> [ Wn1 ] [ Water HM ]

( === WATER MOVEMENT phase 1: horizontal === )
right [ Wp1 ] [ Water WantRight no HM | no Water ] -> [ Wp1 ] [ | Water HM ]
left  [ Wn1 ] [ Water WantLeft  no HM | no Water ] -> [ Wn1 ] [ | Water HM ]

( === WATER MOVEMENT phase 2: vertical === )
down [ Wp1 ] [ Water HM | no Water ] -> [ Wp1 ] [ | Water VM ]
down [ Wn1 ] [ Water HM | no Water ] -> [ Wn1 ] [ | Water VM ]
down [ W0  ] [ Water no VM no WantLeft no WantRight | no Water ] -> [ W0 ] [ | Water VM ]

( === GHOST DOWN (wind=0, VM prevents cascade) === )
down [ W0 ] [ GhostL  no WantLeft  no VM | no GhostL  ] -> [ W0 ] [ | GhostL  VM ]
down [ W0 ] [ GhostR  no WantRight no VM | no GhostR  ] -> [ W0 ] [ | GhostR  VM ]
down [ W0 ] [ GhostL2 no WantLeft  no VM | no GhostL2 ] -> [ W0 ] [ | GhostL2 VM ]
down [ W0 ] [ GhostR2 no WantRight no VM | no GhostR2 ] -> [ W0 ] [ | GhostR2 VM ]
down [ W0 ] [ GhostL3 no WantLeft  no VM | no GhostL3 ] -> [ W0 ] [ | GhostL3 VM ]
down [ W0 ] [ GhostR3 no WantRight no VM | no GhostR3 ] -> [ W0 ] [ | GhostR3 VM ]

( === WIND INPUT === )
[ left  Player W0  ] -> [ Player Wn1 ]
[ left  Player Wp1 ] -> [ Player W0  ]
[ right Player Wn1 ] -> [ Player W0  ]
[ right Player W0  ] -> [ Player Wp1 ]
[ moving Player ] -> [ Player ]

( === LATE RULES === )

( Border Water -> GhostL/R one row below )
late down [ Water WantLeft  no HM | ] -> [ | GhostL  ]
late down [ Water WantRight no HM | ] -> [ | GhostR  ]

( GhostL going further OOB: create GhostL2 one row below )
late down [ GhostL  WantLeft  | no GhostL2 ] -> [ | GhostL2 ]
late       [ GhostL  WantLeft  ]              -> []
( Symmetric GhostR -> GhostR2 )
late down [ GhostR  WantRight | no GhostR2 ] -> [ | GhostR2 ]
late       [ GhostR  WantRight ]              -> []

( GhostL2 going further OOB: create GhostL3 one row below )
late down [ GhostL2 WantLeft  | no GhostL3 ] -> [ | GhostL3 ]
late       [ GhostL2 WantLeft  ]              -> []
( Symmetric GhostR2 -> GhostR3 )
late down [ GhostR2 WantRight | no GhostR3 ] -> [ | GhostR3 ]
late       [ GhostR2 WantRight ]              -> []

( GhostL3/GhostR3 going even further OOB: untracked, destroy )
late [ GhostL3 WantLeft  ] -> []
late [ GhostR3 WantRight ] -> []

( Spawn water )
late [ SpawnPos Tc3 JT no Water ] -> [ Water SpawnPos Tc3 JT ]

( Cleanup )
late [ JT        ] -> []
late [ WantLeft  ] -> []
late [ WantRight ] -> []
late [ HM        ] -> []
late [ VM        ] -> []
