title Magnets (AutumnBench port)
author ported from AutumnBench magnets.sexp

(
  Port of AutumnBench magnets.sexp (GRID_SIZE 16).
  Autumn render keys: fixedMagnet (red, static), mobileMagnet (blue, player-controlled).
  Each Magnet is a 2-cell vertical body: top cell = posPole, bottom = negPole.
    fixedMagnet: FixedTop(7,7) + FixedBot(7,8), never moves.
    mobileMagnet: MobileTop(4,7) + MobileBot(4,8) at start.

  Mechanics:
  1. Arrow keys move mobileMagnet 1 cell (moveNoCollision).
  2. Repulsion: same-pole adjacency (dist==1) blocks the move.
     Blocked destination cells: (6,7), (8,7), (7,6).
     Approach positions needing cancel rules:
       Horizontal: (5,7)right, (9,7)left (same row as FT, existing rules)
       Vertical: (6,6)down, (8,6)down, (6,8)up, (8,8)up
       Diagonal: (6,6)right, (8,6)left
     Implemented via BlkD/BlkU/BlkR/BlkL invisible markers.
  3. Attraction: TWO conditions (same-tick in Autumn; 1-tick lag in PS).
     Condition 7: delta(posPole(mobile), negPole(fixed=(7,8))) in attractVectors
     Condition 8: delta(negPole(mobile), posPole(fixed=(7,7))) in attractVectors
     Trigger positions for MT (posPole):
       (5,8)=cond7->RIGHT   (5,6)=cond8->RIGHT
       (9,8)=cond7->LEFT    (9,6)=cond8->LEFT
       (7,10)=cond7->UP     (7,4)=cond8->DOWN
  4. Deferred: off-grid motion (Autumn allows negative coords; PS clamps).
)

RULES
======

( === ATTRACTION (pre-movement, 1-tick lag) === )

[ MobileTop AttrR ] -> [ right MobileTop AttrR ]
[ MobileTop AttrL ] -> [ left  MobileTop AttrL ]
[ MobileTop AttrD ] -> [ down  MobileTop AttrD ]
[ MobileTop AttrU ] -> [ up    MobileTop AttrU ]

( === REPULSION === )
( Horizontal: same-row cancel rules )
right [ right MobileTop | . | FixedTop ] -> [ MobileTop | . | FixedTop ]
right [ right MobileBot | . | FixedBot ] -> [ MobileBot | . | FixedBot ]
right [ FixedTop | . | left MobileTop ] -> [ FixedTop | . | MobileTop ]
right [ FixedBot | . | left MobileBot ] -> [ FixedBot | . | MobileBot ]

( Vertical/diagonal: cancel via marker objects at approach positions )
[ down  MobileTop BlkD ] -> [ MobileTop BlkD ]
[ up    MobileTop BlkU ] -> [ MobileTop BlkU ]
[ right MobileTop BlkR ] -> [ MobileTop BlkR ]
[ left  MobileTop BlkL ] -> [ MobileTop BlkL ]

( Direct collision cancel: prevent body split when MT hits FixedTop/Bot directly.
  Without these, MT is blocked by collision but MB inherits and executes the
  direction before the collision check, causing MT/MB to split.
  Must fire BEFORE body sync. )
right [ right MobileTop | FixedTop ] -> [ MobileTop | FixedTop ]
right [ right MobileTop | FixedBot ] -> [ MobileTop | FixedBot ]
right [ FixedTop | left MobileTop ] -> [ FixedTop | MobileTop ]
right [ FixedBot | left MobileTop ] -> [ FixedBot | MobileTop ]

( === BODY SYNC: MobileBot follows MobileTop === )
down [ right MobileTop | MobileBot ] -> [ right MobileTop | right MobileBot ]
down [ left  MobileTop | MobileBot ] -> [ left  MobileTop | left  MobileBot ]
down [ up    MobileTop | MobileBot ] -> [ up    MobileTop | up    MobileBot ]
down [ down  MobileTop | MobileBot ] -> [ down  MobileTop | down  MobileBot ]

( === FIXED MAGNETS: never move === )
[ moving FixedTop ] -> [ FixedTop ]
[ moving FixedBot ] -> [ FixedBot ]
