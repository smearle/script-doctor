title count_5 (AutumnBench port)
author ported from AutumnBench count_5.sexp

(
  Port of AutumnBench count_5.sexp (GRID_SIZE 100). Autumn render key: blobs (alias blob->blobs).
  Blob has hidden x-velocity xVel in {-5..5}.
    - left/right adjust xVel (clamped to +/-5) with one-frame lag.
    - Every frame the blob moves by sign(prev xVel).
  Velocity encoded as one of 11 velocity objects (Vn5..V0..Vp5) on the Player cell.
  V0 = velocity 0 (initial), Vn5..Vn1 = negative velocities, Vp1..Vp5 = positive.
  One-frame lag: blob-move rules come before velocity-update rules (PS single-pass).
  Deferred: click (xActive toggle), y-axis (broken in Autumn: down requires yVel>5).
)

realtime_interval 0.1

======
RULES
======

(=== 1. Move blob by CURRENT velocity (= prev xVel, one-frame lag) ===)
(These fire BEFORE velocity-update rules: PS single-pass ordering creates the lag)
[ Vn5 ][ Blob ] -> [ Vn5 ][ left Blob ]
[ Vn4 ][ Blob ] -> [ Vn4 ][ left Blob ]
[ Vn3 ][ Blob ] -> [ Vn3 ][ left Blob ]
[ Vn2 ][ Blob ] -> [ Vn2 ][ left Blob ]
[ Vn1 ][ Blob ] -> [ Vn1 ][ left Blob ]
(V0: no movement)
[ Vp1 ][ Blob ] -> [ Vp1 ][ right Blob ]
[ Vp2 ][ Blob ] -> [ Vp2 ][ right Blob ]
[ Vp3 ][ Blob ] -> [ Vp3 ][ right Blob ]
[ Vp4 ][ Blob ] -> [ Vp4 ][ right Blob ]
[ Vp5 ][ Blob ] -> [ Vp5 ][ right Blob ]

(=== 2. Update velocity from input (each V-object transition fires at most once) ===)
(Right key: increase xVel by 1, clamped at +5)
[ right Player Vn5 ] -> [ Player Vn4 ]
[ right Player Vn4 ] -> [ Player Vn3 ]
[ right Player Vn3 ] -> [ Player Vn2 ]
[ right Player Vn2 ] -> [ Player Vn1 ]
[ right Player Vn1 ] -> [ Player V0 ]
[ right Player V0 ] -> [ Player Vp1 ]
[ right Player Vp1 ] -> [ Player Vp2 ]
[ right Player Vp2 ] -> [ Player Vp3 ]
[ right Player Vp3 ] -> [ Player Vp4 ]
[ right Player Vp4 ] -> [ Player Vp5 ]
[ right Player Vp5 ] -> [ Player Vp5 ]
(Left key: decrease xVel by 1, clamped at -5)
[ left Player Vn5 ] -> [ Player Vn5 ]
[ left Player Vn4 ] -> [ Player Vn5 ]
[ left Player Vn3 ] -> [ Player Vn4 ]
[ left Player Vn2 ] -> [ Player Vn3 ]
[ left Player Vn1 ] -> [ Player Vn2 ]
[ left Player V0 ] -> [ Player Vn1 ]
[ left Player Vp1 ] -> [ Player V0 ]
[ left Player Vp2 ] -> [ Player Vp1 ]
[ left Player Vp3 ] -> [ Player Vp2 ]
[ left Player Vp4 ] -> [ Player Vp3 ]
[ left Player Vp5 ] -> [ Player Vp4 ]

(Player never actually moves - it's a hidden velocity holder)
[ moving Player ] -> [ Player ]
