title count_3 (AutumnBench port)
author ported from AutumnBench count_3.sexp

(
  Port of AutumnBench count_3.sexp (GRID_SIZE 100). Autumn render key: blobs (alias blob->blobs).
  A single Blob has hidden horizontal velocity xVel and vertical velocity yVel in {-3..3}.
    - When xActive (default True): left/right adjust xVel, clamped to [-3,3].
    - When !xActive (after click): up adjusts yVel (down is broken in source: yVel never increases).
    - Every frame the blob moves by sign(prev xVel), sign(prev yVel) -- one-frame velocity lag.
    - click toggles xActive (proxied via action/X key in PS port).
  Deferred: in Autumn, velocity sign(v) gives 1-cell motion regardless of magnitude.
  Bug note: Autumn source has (> (prev yVel) 3) for down -- this never fires (yVel starts 0, can only go negative).
  So down never works; only up (when xActive=False) decreases yVel.
)

realtime_interval 0.1

RULES
======

(--- MOVEMENT: uses PREV velocity (one-frame lag). Run BEFORE velocity update. ---)
(move blob horizontally by sign of current xVel)
[ XVneg ][ Blob ] -> [ XVneg ][ left Blob ]
[ XVpos ][ Blob ] -> [ XVpos ][ right Blob ]

(move blob vertically by sign of current yVel)
[ YVneg ][ Blob ] -> [ YVneg ][ up Blob ]

(--- TOGGLE xActive via action key (proxy for Autumn click) ---)
[ action Player no XInactive ] -> [ Player XInactive ]
[ action Player XInactive ] -> [ Player ]

(--- VELOCITY UPDATE for xVel (only when xActive = no XInactive marker) ---)
(left input: decrease xVel by 1, clamped at -3)
[ left Player no XInactive XP3 ] -> [ Player XP2 ]
[ left Player no XInactive XP2 ] -> [ Player XP1 ]
[ left Player no XInactive XP1 ] -> [ Player ]
[ left Player no XInactive no XVneg no XVpos ] -> [ Player XN1 ]
[ left Player no XInactive XN1 ] -> [ Player XN2 ]
[ left Player no XInactive XN2 ] -> [ Player XN3 ]
(XN3 stays at -3: no rule needed)

(right input: increase xVel by 1, clamped at +3)
[ right Player no XInactive XN3 ] -> [ Player XN2 ]
[ right Player no XInactive XN2 ] -> [ Player XN1 ]
[ right Player no XInactive XN1 ] -> [ Player ]
[ right Player no XInactive no XVneg no XVpos ] -> [ Player XP1 ]
[ right Player no XInactive XP1 ] -> [ Player XP2 ]
[ right Player no XInactive XP2 ] -> [ Player XP3 ]
(XP3 stays at +3: no rule needed)

(--- VELOCITY UPDATE for yVel (only when !xActive = XInactive present) ---)
(up input: decrease yVel by 1, clamped at -3)
[ up Player XInactive YN3 ] -> [ Player XInactive YN3 ]
[ up Player XInactive YN2 ] -> [ Player XInactive YN3 ]
[ up Player XInactive YN1 ] -> [ Player XInactive YN2 ]
[ up Player XInactive no YVneg ] -> [ Player XInactive YN1 ]
(down: source bug -> never fires, no rule needed)

(--- cancel Player's own arrow motion -- must come AFTER velocity-update rules ---)
[ moving Player ] -> [ Player ]
