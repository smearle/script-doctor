title Space Invaders (AutumnBench port)
author ported from AutumnBench space_invaders.sexp

(
  Port of AutumnBench space_invaders.sexp (GRID_SIZE=16).

  Autumn mechanics:
    - 16x16 play area. enemies1 at y=1 x=1,4,7,10,13; enemies2 at y=3 x=2,5,8,11,14.
    - Hero at (8,15); left/right to move, up to shoot.
    - Hero bullet: appears at hero when up pressed, moves up 1/tick.
    - EnemyBullet moves down 1/tick. Spawns every 5 frames (STOCHASTIC: uniformChoice).
    - enemies1 move right (prev_time%10==0), left (prev_time%10==5); enemies2 opposite.
    - Collisions: bullet kills enemy; bullet cancels enemyBullet; enemyBullet kills hero.

  Timer design (10-cell HUD row at y=16, cols 0-9):
    TCursor starts at T0 (col 0). Event triggers fire BEFORE cursor advances.
    So: trigger at T0 = fires on frames 1,11,21... (matches prev_time%10==0)
         trigger at T2 = fires on frames 3,13,23... (matches prev_time%5==2 and prev_time%10==2)
         trigger at T5 = fires on frames 6,16,26... (matches prev_time%10==5)
         trigger at T7 = fires on frames 8,18,28... (matches prev_time%5==2 and prev_time%10==7)
    After frame 9 (cursor at T9), late rule wraps cursor back to T0.

  Stochastic deviation: enemyBullet X position uses uniformChoice among enemies.
  PS RNG differs, so enemy bullet positions will diverge from Autumn at step 3+.
  The deterministic parts (enemy positions, hero, hero bullets) are matched exactly.
)

RULES
======

[BottomEdge EnemyBullet] -> [BottomEdge]
( player bullets clear off the TOP of the screen instead of stacking at row 0 )
[TopEdge Bullet] -> [TopEdge]

(Player can only move left/right)
[down Player ] -> [Player]

( === HERO SHOOT: spawn bullet when up pressed === )
[ up Player ] -> [ Player Bullet ]

( === ENEMY MOVEMENT PHASE A: e1 right, e2 left (fires frames 1,11,21...) === )
( Put BEFORE cursor advance so both fire in same pass )
[ TCursor T0 ] [ Enemies1 ] -> [ TCursor T0 ] [ right Enemies1 ]
[ TCursor T0 ] [ Enemies2 ] -> [ TCursor T0 ] [ left Enemies2 ]

( === ENEMY MOVEMENT PHASE B: e1 left, e2 right (fires frames 6,16,26...) === )
[ TCursor T5 ] [ Enemies1 ] -> [ TCursor T5 ] [ left Enemies1 ]
[ TCursor T5 ] [ Enemies2 ] -> [ TCursor T5 ] [ right Enemies2 ]

( === TIMER ADVANCE (after event triggers) === )
[ stationary TCursor ] -> [ right TCursor ]

( === HERO BULLET MOVEMENT: moves up 1/tick === )
[ Bullet ] -> [ up Bullet ]

( === ENEMY BULLET MOVEMENT: moves down 1/tick === )
[ EnemyBullet ] -> [ down EnemyBullet ]

( === COLLISIONS (late) === )

( Hero bullet kills enemy: BOTH the bullet and the enemy are removed )
late [ Bullet Enemies1 ] -> []
late [ Bullet Enemies2 ] -> []

( Hero bullet vs enemy bullet: both removed )
late [ Bullet EnemyBullet ] -> []

( Enemy bullet hits hero: hero becomes dead )
late [ EnemyBullet Player ] -> [ HeroDead ]

( === ENEMY BULLET SPAWN (late, no movement this frame) === )
( Autumn: bullet spawns at prev enemy pos, no moveDown on spawn frame )
( Fires on frames 3,13,23... (cursor at T3 after regular phase: moved T2->T3) )
( Fires on frames 8,18,28... (cursor at T8 after regular phase: moved T7->T8) )
late random [ TCursor T3 ] [ Enemy no EnemyBullet ] -> [ TCursor T3 ] [ Enemy EnemyBullet ]
late random [ TCursor T8 ] [ Enemy no EnemyBullet ] -> [ TCursor T8 ] [ Enemy EnemyBullet ]

( === TIMER WRAP (late): cursor at T10 -> wrap back to T0 (period = 10 ticks) === )
late [ TCursor T10 ] [ T0 no TCursor ] -> [ T10 ] [ T0 TCursor ]
