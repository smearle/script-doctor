title balls (AutumnBench port)
author ported from AutumnBench balls.sexp

(
  Port of AutumnBench balls.sexp. GRID_SIZE=12.

  Autumn render_all keys: goal, wall, ball_a, ball_b.

  Grid 13x13 (cols 0-12, rows 0-12). Harness compares cols 0-11, rows 0-11.
  Col 12 / row 12 = off-grid bounce zones (Autumn x/y=GRID_SIZE=12 positions).

  Ball directions (Autumn numbering):
    1=N(0,-1) 2=NE(+1,-1) 3=E(+1,0) 4=SE(+1,+1)
    5=S(0,+1) 6=SW(-1,+1) 7=W(-1,0) 8=NW(-1,-1)

  Movement uses positional teleport rules (not movement keywords) to enable
  diagonal movement within one PS tick:
    Cardinal: up/down/left/right [Ball no VM | no Ball] -> [ | Ball VM]
    Diagonal: two phases, HM marks after horizontal, VM after vertical.

  Bounce detection (fires before movement):
    BoundL at col 0: W->E, SW->SE, NW->NE
    BoundT at row 0: N->S, NE->SE, NW->SW
    BoundR at col 12: E->W, NE->NW, SE->SW
    BoundB at row 12: S->N, SE->NE, SW->NW

  Ball-ball collision (late, after all movement):
    When BallA and BallB in same cell: BallA->SW(6), BallB->NE(2).

  Wall: moves L/R only; bounded x=1..11 via WallBound (same layer as Wall).
  Deferred: wall visibility toggle (click); ball-wall bounce (requires visible wall).
)

realtime_interval 0.1

( === BALL MOVEMENT using positional teleport === )
( Balls move BEFORE wall blocking is detected, matching Autumn's evaluation order:
  all ball initnext formulas compute new positions, then the wall on-handler runs
  isFreePos against the already-updated ball positions. )

( Cardinal N -- dir 1: move up one cell )
up [ BallA1 no VM | no BallA1 ] -> [ | BallA1 VM ]
up [ BallB1 no VM | no BallB1 ] -> [ | BallB1 VM ]

( Cardinal E -- dir 3: move right )
right [ BallA3 no VM | no BallA3 ] -> [ | BallA3 VM ]
right [ BallB3 no VM | no BallB3 ] -> [ | BallB3 VM ]

( Cardinal S -- dir 5: move down )
down [ BallA5 no VM | no BallA5 ] -> [ | BallA5 VM ]
down [ BallB5 no VM | no BallB5 ] -> [ | BallB5 VM ]

( Cardinal W -- dir 7: move left )
left [ BallA7 no VM | no BallA7 ] -> [ | BallA7 VM ]
left [ BallB7 no VM | no BallB7 ] -> [ | BallB7 VM ]

( Diagonal NE -- dir 2: phase 1 = right, phase 2 = up )

( === WALL-BLOCK DETECTION (before wall movement) === )
( Confirmed by probe: balls never block wall movement in Autumn. The wall's
  moveRightNoCollision / moveLeftNoCollision only checks:
   - grid boundary (off-grid positions blocked)
   - prev_wall (save_state artifact: prev_wall is always the initial x=4 position in BFS states)
  Balls and the wall can coexist at the same cell.
  Replicate the two real blockers:
   - WallBound at x=0,12 rows 9-11: boundary blocking (also covers goal at (0,10))
   - WallHome at x=4 rows 9-11: prev_wall=4 save_state artifact )
right [ Wall | WallHome ] -> [ Wall NoMoveR | WallHome ]
left [ Wall | WallHome ] -> [ Wall NoMoveL | WallHome ]

( Propagate NoMoveR/L through all wall cells (safety, since WallHome covers all 3 rows). )
[ Wall NoMoveR | Wall no NoMoveR ] -> [ Wall NoMoveR | Wall NoMoveR ]
[ Wall NoMoveL | Wall no NoMoveL ] -> [ Wall NoMoveL | Wall NoMoveL ]

( === WALL MOVEMENT: Player's L/R input drives Wall (only if no block flag) === )
[ right Player ] [ Wall no NoMoveR ] -> [ right Player ] [ right Wall ]
[ left Player ] [ Wall no NoMoveL ] -> [ left Player ] [ left Wall ]
( Cancel Player movement after all walls are updated )
[ moving Player ] -> [ Player ]
[ up Player ] -> [ Player ]
[ down Player ] -> [ Player ]

( === BALL-BALL COLLISION (late, after all movement) === )

late [ Coll BallA ] -> [ Coll BallA6 ]
late [ Coll BallB ] -> [ Coll BallB2 ]
late [ Coll ] -> []
