(
  Port of AutumnBench carrace.sexp (GRID_SIZE=13).

  render_all keys compared: playerCar, tracks, obstacles, finish
  eval.json aliases: car->playercar, obstacle->obstacles, track->tracks, finishline->finish

  Autumn's isWithinBounds() is broken for negative coords (returns true), so the car
  can leave the grid.  We model off-grid states explicitly:
    OGL1..OGL5  = car is 1..5 cells off-grid to the LEFT  (placed at x=0, y=car_y)
    OGR1..OGR3  = car is 1..3 cells off-grid to the RIGHT (placed at x=12, y=car_y)
  These are helpers (not aliased), so the parity checker ignores them.

  A fixed invisible Player anchor at (6,13) receives all key input; rules relay
  input to Car / OGLk / OGRk via two-bracket rules (arc_slack pattern).

  Clock: 11-tick cycle matches Autumn's UPDATE_RATE=10 (+1 for the init frame).
    ClockHand at Col0 (x=0,y=13): autonomous movement fires this tick.

  LeftBound at x=0, y=2..12: marks left-edge cells for OGL conversion.
  PlayRightBound at x=12, y=0..12: marks right-edge cells for OGR conversion.
  (Track already at (0,0) and (0,1); car blocked from those by Track being in same
   collision layer as Car.)
)

( === OFF-GRID LEFT: car goes off-grid when left pressed at x=0 === )
( Must come BEFORE the regular left-relay and before moving-Player cancel )
( InputActive suppresses auto-up on this key-press frame )
[ left Player ] [ Car LeftBound no ResetNow ] -> [ Player ] [ OGL1 LeftBound InputActive ]

( === OFF-GRID RIGHT: car goes off-grid when right pressed at x=12 === )
[ right Player ] [ Car PlayRightBound no ResetNow ] -> [ Player ] [ OGR1 PlayRightBound InputActive ]

( === OGL TRANSITIONS: left/right = deeper/shallower; up/down = suppress auto-up only === )
[ left Player ]  [ OGL1 ] -> [ Player ] [ OGL2 InputActive ]
[ left Player ]  [ OGL2 ] -> [ Player ] [ OGL3 InputActive ]
[ left Player ]  [ OGL3 ] -> [ Player ] [ OGL4 InputActive ]
[ left Player ]  [ OGL4 ] -> [ Player ] [ OGL5 InputActive ]
[ left Player ]  [ OGL5 ] -> [ Player ] [ OGL5 InputActive ]
[ right Player ] [ OGL5 ] -> [ Player ] [ OGL4 InputActive ]
[ right Player ] [ OGL4 ] -> [ Player ] [ OGL3 InputActive ]
[ right Player ] [ OGL3 ] -> [ Player ] [ OGL2 InputActive ]
[ right Player ] [ OGL2 ] -> [ Player ] [ OGL1 InputActive ]
[ right Player ] [ OGL1 ] -> [ Player ] [ Car InputActive ]
[ up Player ]    [ OGL1 ] -> [ Player ] [ OGL1 InputActive ]
[ up Player ]    [ OGL2 ] -> [ Player ] [ OGL2 InputActive ]
[ up Player ]    [ OGL3 ] -> [ Player ] [ OGL3 InputActive ]
[ up Player ]    [ OGL4 ] -> [ Player ] [ OGL4 InputActive ]
[ up Player ]    [ OGL5 ] -> [ Player ] [ OGL5 InputActive ]
[ down Player ]  [ OGL1 ] -> [ Player ] [ OGL1 InputActive ]
[ down Player ]  [ OGL2 ] -> [ Player ] [ OGL2 InputActive ]
[ down Player ]  [ OGL3 ] -> [ Player ] [ OGL3 InputActive ]
[ down Player ]  [ OGL4 ] -> [ Player ] [ OGL4 InputActive ]
[ down Player ]  [ OGL5 ] -> [ Player ] [ OGL5 InputActive ]

( === OGR TRANSITIONS: right = go deeper, left = come back === )
[ right Player ] [ OGR1 ] -> [ Player ] [ OGR2 InputActive ]
[ right Player ] [ OGR2 ] -> [ Player ] [ OGR3 InputActive ]
[ right Player ] [ OGR3 ] -> [ Player ] [ OGR3 InputActive ]
[ left Player ]  [ OGR3 ] -> [ Player ] [ OGR2 InputActive ]
[ left Player ]  [ OGR2 ] -> [ Player ] [ OGR1 InputActive ]
[ left Player ]  [ OGR1 ] -> [ Player ] [ Car InputActive ]
[ up Player ]    [ OGR1 ] -> [ Player ] [ OGR1 InputActive ]
[ up Player ]    [ OGR2 ] -> [ Player ] [ OGR2 InputActive ]
[ up Player ]    [ OGR3 ] -> [ Player ] [ OGR3 InputActive ]
[ down Player ]  [ OGR1 ] -> [ Player ] [ OGR1 InputActive ]
[ down Player ]  [ OGR2 ] -> [ Player ] [ OGR2 InputActive ]
[ down Player ]  [ OGR3 ] -> [ Player ] [ OGR3 InputActive ]

( === RELAY INPUT TO CAR (when on-grid) === )
( left/right move car AND mark InputActive to suppress auto-up )
[ left Player ]  [ Car ] -> [ Player ] [ left Car InputActive ]
[ right Player ] [ Car ] -> [ Player ] [ right Car InputActive ]
( up/down only mark InputActive (speed change in Autumn, not modeled in PS) )
[ up Player ]    [ Car ] -> [ Player ] [ Car InputActive ]
[ down Player ]  [ Car ] -> [ Player ] [ Car InputActive ]

( === CANCEL PLAYER ANCHOR MOVEMENT (after all relay rules, catches no-car/no-ogl case) === )
[ moving Player ] -> [ Player ]

( === RESET DETECTION (must fire before auto-movement) === )
[ ClockHand Col0 ] [ Car Obstacle ] -> [ ClockHand Col0 ResetNow ] [ Car Obstacle ]
[ ClockHand Col0 ] [ Car FinishLine ] -> [ ClockHand Col0 ResetNow ] [ Car FinishLine ]

( === AUTO-MOVEMENT (update frame, no reset, no input on car) === )
[ ClockHand Col0 no ResetNow ] [ no InputActive Car ] -> [ ClockHand Col0 ] [ up Car ]
[ ClockHand Col0 no ResetNow ] [ stationary Obstacle ] -> [ ClockHand Col0 ] [ down Obstacle ]

( === CLOCK ADVANCE === )
[ stationary ClockHand ] -> [ right ClockHand ]

( === LATE: clock wrap === )
late [ ClockHand RightEdge ] -> [ RightEdge Wrap ]
late [ Wrap ] [ Col0 ] -> [ ] [ ClockHand Col0 ]

( === LATE: reset execution === )
late [ ResetNow ] [ Car ] -> [ ResetNow ] [ ]
late [ ResetNow ] [ SpawnC no Car ] -> [ ResetNow ] [ SpawnC Car ]

late [ ResetNow ] [ Obstacle ] -> [ ResetNow ] [ ]
late [ ResetNow ] [ SpawnO1 no Obstacle ] -> [ ResetNow ] [ SpawnO1 Obstacle ]
late [ ResetNow ] [ SpawnO2 no Obstacle ] -> [ ResetNow ] [ SpawnO2 Obstacle ]
late [ ResetNow ] [ SpawnO3 no Obstacle ] -> [ ResetNow ] [ SpawnO3 Obstacle ]

( === LATE: cleanup === )
late [ ResetNow ] -> [ ]
late [ InputActive ] -> [ ]
