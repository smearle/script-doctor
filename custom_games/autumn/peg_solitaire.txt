(
  Port of AutumnBench peg_solitaire.sexp (GRID_SIZE=7).
  Classic English peg solitaire on a cross/plus board.
  Initial state: 32 pegs filling the cross shape, center hole at (3,3).

  Autumn semantics:
  1. Click a filled peg to SELECT it (active=true; ALL others set active=false globally).
  2. Click an empty hole: if the active peg is EXACTLY 2 cells away (cardinal),
     perform a jump: active cell -> Hole, mid cell -> Hole, target -> Peg.
     Autumn only checks distance=2 (not whether mid is filled).
  3. Active state persists across ticks until a new peg is selected.
  4. After a jump, the active marker stays on the source (now-hole) cell.

  compare_color: true. Peg = #0000ff (CSS blue). Hole = #d3d3d3 (CSS lightgray).
  Active/NewActive/Player are helpers (ignored in comparison).
)

realtime_interval 0.1

( Mid is Peg: )

( Mid is Hole: )
