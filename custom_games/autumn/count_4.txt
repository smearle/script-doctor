title count_4 (AutumnBench port)
author ported from AutumnBench count_4.sexp

(
  Port of AutumnBench count_4.sexp (GRID_SIZE 100). Autumn render key: blobs (alias blob->blobs).
  A single Blob starts at (50,50) with hidden xVel and yVel in {-4..4}.
    - xActive starts true; click toggles it (unportable: PS click = noop, deferred).
    - When xActive=true: left/right adjust xVel (clamped to [-4,4]); up/down do nothing.
    - When xActive=false: up adjusts yVel (clamped to [-4,-1]); down has a SOURCE BUG
      (condition yVel>4 can never be true when yVel<=-4 range, so down never fires).
    - Every frame: blob moves by (sign(xVel), sign(yVel)) - one-frame velocity lag.
  Velocity is encoded as marker objects N4..N1, VZ, P1..P4 co-located with Player at (0,0).
  With arrows-only policy: xActive stays true always, yVel stays 0, only xVel matters.
  Deferred: click toggle of xActive; yVel (never reachable with arrows-only policy).
)

======
RULES
======

( 1. Move blob by CURRENT velocity markers = previous frame's xVel, one-frame lag )
[ N4 ][ Blob ] -> [ N4 ][ left Blob ]
[ N3 ][ Blob ] -> [ N3 ][ left Blob ]
[ N2 ][ Blob ] -> [ N2 ][ left Blob ]
[ N1 ][ Blob ] -> [ N1 ][ left Blob ]
( VZ: no movement, blob stays put )
[ P1 ][ Blob ] -> [ P1 ][ right Blob ]
[ P2 ][ Blob ] -> [ P2 ][ right Blob ]
[ P3 ][ Blob ] -> [ P3 ][ right Blob ]
[ P4 ][ Blob ] -> [ P4 ][ right Blob ]

( 2. Velocity update from left input - decrease xVel by 1, clamped at -4 )
[ left Player N4 ] -> [ Player N4 ]
[ left Player N3 ] -> [ Player N4 ]
[ left Player N2 ] -> [ Player N3 ]
[ left Player N1 ] -> [ Player N2 ]
[ left Player VZ  ] -> [ Player N1 ]
[ left Player P1  ] -> [ Player VZ ]
[ left Player P2  ] -> [ Player P1 ]
[ left Player P3  ] -> [ Player P2 ]
[ left Player P4  ] -> [ Player P3 ]

( 3. Velocity update from right input - increase xVel by 1, clamped at +4 )
[ right Player N4 ] -> [ Player N3 ]
[ right Player N3 ] -> [ Player N2 ]
[ right Player N2 ] -> [ Player N1 ]
[ right Player N1 ] -> [ Player VZ ]
[ right Player VZ  ] -> [ Player P1 ]
[ right Player P1  ] -> [ Player P2 ]
[ right Player P2  ] -> [ Player P3 ]
[ right Player P3  ] -> [ Player P4 ]
[ right Player P4  ] -> [ Player P4 ]

( 4. Register cells never physically move )
[ moving Player ] -> [ Player ]
[ moving N4 ] -> [ N4 ]
[ moving N3 ] -> [ N3 ]
[ moving N2 ] -> [ N2 ]
[ moving N1 ] -> [ N1 ]
[ moving VZ ] -> [ VZ ]
[ moving P1 ] -> [ P1 ]
[ moving P2 ] -> [ P2 ]
[ moving P3 ] -> [ P3 ]
[ moving P4 ] -> [ P4 ]
