title gameOfLife (AutumnBench port)
author ported from AutumnBench gameOfLife.sexp

(
  Game of Life (16x16). Autumn render key: particles (alias particledead/particleliving).
  compare_color=true: state is color only (living=lightpink #ffb6c1, dead=black #000000).

  Click cursor = Player (visible box, top layer). action = click at the cursor cell:
    - on a normal cell -> make it alive
    - on ButtonNext (green, 0,15) -> run ONE Conway generation
    - on ButtonReset (silver, 15,15) -> clear all to dead

  Correct 8-neighbour count (the hard part): each OldAlive deposits ONE distinct token
  into each of its 8 neighbours (orthogonals directly; diagonals via a one-cell relay).
  The count is then decoded by consuming one token per level (N0->N1->...). Distinct
  token types guarantee each neighbour is counted exactly once (no cascade).
)

======
RULES
======

(--- CLICK a normal cell -> make it alive (exclude the two buttons) ---)
[ action Player ParticleDead no ButtonNext no ButtonReset ] -> [ Player ParticleLiving ]

(--- RESET (grey button): clear all living to dead ---)
[ action Player ButtonReset ] -> [ Player ButtonReset KillAll ]
[ KillAll ] [ ParticleLiving ] -> [ KillAll ] [ ParticleDead ]
late [ KillAll ] -> []

(--- STEP (green button): one Conway generation ---)
[ action Player ButtonNext ] -> [ Player ButtonNext GoLGo ]
[ GoLGo ] [ ParticleLiving ] -> [ GoLGo ] [ ParticleLiving OldAlive ]

(every cell starts at neighbour-count 0)
late [ GoLGo ] [ ParticleDead no Ncount ] -> [ GoLGo ] [ ParticleDead N0 ]
late [ GoLGo ] [ ParticleLiving no Ncount ] -> [ GoLGo ] [ ParticleLiving N0 ]

(deposit one distinct token into each of the 8 neighbours of every OldAlive)
late down  [ OldAlive | no nU ] -> [ OldAlive | nU ]
late up    [ OldAlive | no nD ] -> [ OldAlive | nD ]
late right [ OldAlive | no nL ] -> [ OldAlive | nL ]
late left  [ OldAlive | no nR ] -> [ OldAlive | nR ]
late right [ OldAlive | no RelR ] -> [ OldAlive | RelR ]
late down  [ RelR | no nUL ] -> [ RelR | nUL ]
late up    [ RelR | no nDL ] -> [ RelR | nDL ]
late [ RelR ] -> []
late left  [ OldAlive | no RelL ] -> [ OldAlive | RelL ]
late down  [ RelL | no nUR ] -> [ RelL | nUR ]
late up    [ RelL | no nDR ] -> [ RelL | nDR ]
late [ RelL ] -> []

(decode: consume one token per level to get the neighbour count)
late [ N0 Ntok ] -> [ N1 ]
late [ N1 Ntok ] -> [ N2 ]
late [ N2 Ntok ] -> [ N3 ]
late [ N3 Ntok ] -> [ N4 ]
late [ N4 Ntok ] -> [ N5 ]
late [ N5 Ntok ] -> [ N6 ]
late [ N6 Ntok ] -> [ N7 ]
late [ N7 Ntok ] -> [ N8 ]

(birth/death)
late [ GoLGo ] [ ParticleLiving N2 ] -> [ GoLGo ] [ ParticleLiving Survive ]
late [ GoLGo ] [ ParticleLiving N3 ] -> [ GoLGo ] [ ParticleLiving Survive ]
late [ GoLGo ] [ ParticleLiving no Survive ] -> [ GoLGo ] [ ParticleDead ]
late [ GoLGo ] [ ParticleDead N3 ] -> [ GoLGo ] [ ParticleLiving ]

(cleanup)
late [ Survive ] -> []
late [ OldAlive ] -> []
late [ N0 ] -> []
late [ N1 ] -> []
late [ N2 ] -> []
late [ N3 ] -> []
late [ N4 ] -> []
late [ N5 ] -> []
late [ N6 ] -> []
late [ N7 ] -> []
late [ N8 ] -> []
late [ GoLGo ] -> []
