title masters_logic (AutumnBench port)
author ported from AutumnBench masters_logic.sexp

(
  Port of masters_logic.sexp: a Mastermind-style game on a 12x12 grid.
  enterButton at (0,0): lightpink. curr_guess: 4 cells at x=3-6, y=1.
  Clicking a guess cell cycles its color grey->red->green->blue->yellow->purple->orange->grey.
  An invisible Player cursor walks the grid; action (X) = click at current cell.
  compare_color: true - each Autumn color state is a distinct PS object with hex
  equal to the CSS RGB of the Autumn color name.
  Hints use uniformChoice (random) and correct_answer is random at init - skipped.
  prev_guesses partially modeled but unlikely to appear in 8-step tests.
)

realtime_interval 0.1
