title Pacman (AutumnBench port)
author ported from AutumnBench pacman.sexp

(
  Port of AutumnBench pacman.sexp (GRID_SIZE=10).

  Autumn mechanics:
    - 10x10 play area, Autumn (x=col, y=row), y down.
    - Pacman: arrow-controlled, blocked by walls.
    - Ghosts: move every 3rd frame (Autumn timestep%3==0: frames 3,6,9,...).
      Chase logic: horizontal-first (x-priority). If ghost.x != pac.x, move x.
      Else if ghost.y != pac.y, move y.
    - Pellets: eaten with 1-frame lag (Autumn uses prev semantics).
    - Pacman death: Autumn interpreter bug - pacman.alive never becomes false.
      Not modeled (matches actual Autumn behavior).

  Timer: HUD strip at row 20, 4 cells H0(col0) H1(col1) H2(col2) TStop(col3).
    TCursor moves right 1 cell per frame (movement physics, not substitution).
    Cursor starts at H1: H1->H2(fr1), H2->TStop(fr2, late:wrap+GhostTick), H0->H1(fr3)...
    Ghost AI (PacL/PacR flood + GMove tags) runs in late of frames 2,5,8,...
    Ghost moves (via GMove) in regular of frames 3,6,9,... matching Autumn timestep%3==0.

  Off-grid handling (Autumn isWithinBounds bug: all directions unbounded):
    - Right/Down: PS grid extended to 20x20 play area; pacman wanders into cols/rows 10-19.
      Those cells are outside the parity checker's [0,9]x[0,9] window, so invisible = match.
    - Up (y<0): TopBorder markers in row 0; UpMark detects UP-pressed-at-border; OffTop1/2/Deep
      track off-top state at (x_col,0) with TopSeed seeding ghost AI as if pacman above row 0.
    - Left (x<0): LeftBorder markers in col 0; LeftMark detects LEFT-pressed-at-border;
      OffLeft1/2/Deep track off-left state at (0,y_row) with LeftSeed seeding ghost AI.
    - Further edges (x<0 AND y<0, etc.): OffTop and OffLeft are mutually exclusive;
      corner cases are off-grid in both checkers; ghost AI remains correct (all ghosts
      chase toward positive coords, horizontal priority gives correct direction).
)

( === PLAYER MOVEMENT: blocked by Wall === )
[ > Player | Wall ] -> [ Player | Wall ]

( === TIMER ADVANCE: cursor moves right 1 cell per frame === )
[ stationary TCursor ] -> [ right TCursor ]

( === GHOST MOVEMENT: apply GMove direction from previous late phase === )
[ GhostR GRMoveR ] -> [ right GhostR ]
[ GhostR GRMoveL ] -> [ left GhostR ]
[ GhostR GRMoveU ] -> [ up GhostR ]
[ GhostR GRMoveD ] -> [ down GhostR ]
[ GhostC GCMoveR ] -> [ right GhostC ]
[ GhostC GCMoveL ] -> [ left GhostC ]
[ GhostC GCMoveU ] -> [ up GhostC ]
[ GhostC GCMoveD ] -> [ down GhostC ]

( Clean up GMove after applying )
[ GRMoveR ] -> []
[ GRMoveL ] -> []
[ GRMoveU ] -> []
[ GRMoveD ] -> []
[ GCMoveR ] -> []
[ GCMoveL ] -> []
[ GCMoveU ] -> []
[ GCMoveD ] -> []

( === CLEANUP FROM PREVIOUS FRAME === )
[ GhostTick ] -> []
[ PacL ] -> []
[ PacR ] -> []
[ PacAbove ] -> []
[ PacBelow ] -> []

( === OFF-TOP: tag UP/DOWN inputs === )
[ up Player ] -> [ up Player UpMark ]
[ down OffTop1 ] -> [ OffTop1 DownMark ]
[ down OffTop2 ] -> [ OffTop2 DownMark ]
[ down OffTopDeep ] -> [ OffTopDeep DownMark ]
( Going deeper off-top: convert OffTop type, UP blocked at row 0 )
[ up OffTop1 ] -> [ up OffTop2 ]
[ up OffTop2 ] -> [ up OffTopDeep ]
[ up OffTopDeep ] -> [ up OffTopDeep ]

( === OFF-LEFT: tag LEFT/RIGHT inputs === )
[ left Player ] -> [ left Player LeftMark ]
[ right OffLeft1 ] -> [ OffLeft1 RightMark ]
[ right OffLeft2 ] -> [ OffLeft2 RightMark ]
[ right OffLeftDeep ] -> [ OffLeftDeep RightMark ]
( Going deeper off-left: cancel LEFT movement, tag )
[ left OffLeft1 ] -> [ OffLeft1 LeftMark ]
[ left OffLeft2 ] -> [ OffLeft2 LeftMark ]
[ left OffLeftDeep ] -> [ OffLeftDeep LeftMark ]

( === PELLET EATING === )
late [ Pellet PelMark ] -> [ PelMark ]
late [ PelMark ] -> []

( === TIMER WRAP (late): cursor at TStop -> teleport to H0, fire ghost AI === )
late [ TCursor TStop ] [ H0 no TCursor ] -> [ TStop ] [ H0 TCursor GhostTick ]

( === OFF-TOP LATE TRANSITIONS === )
late [ Player UpMark TopBorder ] -> [ OffTop1 TopSeed TopBorder ]
late [ UpMark ] -> []
late [ OffTop1 no TopSeed ] -> [ OffTop1 TopSeed ]
late [ OffTop2 no TopSeed ] -> [ OffTop2 TopSeed ]
late [ OffTopDeep no TopSeed ] -> [ OffTopDeep TopSeed ]
late [ no OffTop1 no OffTop2 no OffTopDeep TopSeed ] -> []
late [ OffTop1 DownMark TopSeed ] -> [ Player ]
late [ OffTop2 DownMark TopSeed ] -> [ OffTop1 TopSeed ]
late [ OffTopDeep DownMark TopSeed ] -> [ OffTop2 TopSeed ]
late [ DownMark ] -> []

( === OFF-LEFT LATE TRANSITIONS === )
late [ Player LeftMark LeftBorder ] -> [ OffLeft1 LeftSeed LeftBorder ]
late [ LeftMark ] -> []
late [ OffLeft1 no LeftSeed ] -> [ OffLeft1 LeftSeed ]
late [ OffLeft2 no LeftSeed ] -> [ OffLeft2 LeftSeed ]
late [ OffLeftDeep no LeftSeed ] -> [ OffLeftDeep LeftSeed ]
late [ no OffLeft1 no OffLeft2 no OffLeftDeep LeftSeed ] -> []
late [ OffLeft1 RightMark LeftSeed ] -> [ Player ]
late [ OffLeft2 RightMark LeftSeed ] -> [ OffLeft1 LeftSeed ]
late [ OffLeftDeep RightMark LeftSeed ] -> [ OffLeft2 LeftSeed ]
late [ OffLeft1 LeftMark LeftSeed ] -> [ OffLeft2 LeftSeed ]
late [ OffLeft2 LeftMark LeftSeed ] -> [ OffLeftDeep LeftSeed ]
late [ OffLeftDeep LeftMark LeftSeed ] -> [ OffLeftDeep LeftSeed ]
late [ RightMark ] -> []

( === GHOST AI (late rules, fires when GhostTick present) === )

( Flood PacL: player's column and all cells to the left )
late [ GhostTick ] [ Player no PacL ] -> [ GhostTick ] [ Player PacL ]
late [ GhostTick ] [ TopSeed no PacL ] -> [ GhostTick ] [ TopSeed PacL ]
late left [ PacL | no PacL ] -> [ PacL | PacL ]
late up [ PacL | no PacL ] -> [ PacL | PacL ]
late down [ PacL | no PacL ] -> [ PacL | PacL ]

( Flood PacR: player's column and all cells to the right )
late [ GhostTick ] [ Player no PacR ] -> [ GhostTick ] [ Player PacR ]
late [ GhostTick ] [ TopSeed no PacR ] -> [ GhostTick ] [ TopSeed PacR ]
late [ GhostTick ] [ LeftSeed no PacR ] -> [ GhostTick ] [ LeftSeed PacR ]
late right [ PacR | no PacR ] -> [ PacR | PacR ]
late up [ PacR | no PacR ] -> [ PacR | PacR ]
late down [ PacR | no PacR ] -> [ PacR | PacR ]

( PacAbove: cells strictly above player in player's column )
late up [ Player | no PacAbove ] -> [ Player | PacAbove ]
late up [ PacAbove | no PacAbove ] -> [ PacAbove | PacAbove ]

( PacBelow: cells strictly below player in player's column )
late down [ Player | no PacBelow ] -> [ Player | PacBelow ]
late down [ PacBelow | no PacBelow ] -> [ PacBelow | PacBelow ]
( When off-top, TopSeed seeds PacBelow downward into the play area )
late down [ TopSeed | no PacBelow ] -> [ TopSeed | PacBelow ]

( Assign GMove to GhostR: horizontal priority )
late [ GhostTick ] [ GhostR PacL no PacR no GRMoveR no GRMoveL no GRMoveU no GRMoveD ] -> [ GhostTick ] [ GhostR GRMoveR ]
late [ GhostTick ] [ GhostR PacR no PacL no GRMoveR no GRMoveL no GRMoveU no GRMoveD ] -> [ GhostTick ] [ GhostR GRMoveL ]
late [ GhostTick ] [ GhostR PacL PacR PacAbove no GRMoveR no GRMoveL no GRMoveU no GRMoveD ] -> [ GhostTick ] [ GhostR GRMoveD ]
late [ GhostTick ] [ GhostR PacL PacR PacBelow no GRMoveR no GRMoveL no GRMoveU no GRMoveD ] -> [ GhostTick ] [ GhostR GRMoveU ]

( Assign GMove to GhostC: horizontal priority )
late [ GhostTick ] [ GhostC PacL no PacR no GCMoveR no GCMoveL no GCMoveU no GCMoveD ] -> [ GhostTick ] [ GhostC GCMoveR ]
late [ GhostTick ] [ GhostC PacR no PacL no GCMoveR no GCMoveL no GCMoveU no GCMoveD ] -> [ GhostTick ] [ GhostC GCMoveL ]
late [ GhostTick ] [ GhostC PacL PacR PacAbove no GCMoveR no GCMoveL no GCMoveU no GCMoveD ] -> [ GhostTick ] [ GhostC GCMoveD ]
late [ GhostTick ] [ GhostC PacL PacR PacBelow no GCMoveR no GCMoveL no GCMoveU no GCMoveD ] -> [ GhostTick ] [ GhostC GCMoveU ]

( Mark pellet when player overlaps it (1-frame lag: mark now, remove next frame) )
late [ Player Pellet no PelMark ] -> [ Player Pellet PelMark ]
