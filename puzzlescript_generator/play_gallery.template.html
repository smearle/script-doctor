Same Level, New Rules

Each level below comes from a held-out human PuzzleScript game. A small transformer saw the level with its objects, legend and collision layers, and wrote only the rules and win conditions. Every game listed compiles in the reference engine and changes the level under random play. Samples that behaved identically under 16 shared random action sequences are listed once.

This viewer blocks the code that PuzzleScript generates while it runs, so the games cannot play here. Each game shows a still of its level instead. Use Copy source, paste it into the PuzzleScript editor, and press Run.
