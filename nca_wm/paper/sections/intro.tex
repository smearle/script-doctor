Learned world models are typically trained on pixel observations, with
a high-capacity CNN, U-Net, or video Transformer paired to an
action-conditioned dynamics module. This is a natural fit for visually
rich, mechanically uniform environments, but a less natural one for
games whose difficulty lies in a large space of symbolic rule systems
rather than in rendering.

PuzzleScript games are such a regime. Each game is specified by a short
text file of object kinds, layered grid levels, and declarative rewrite
rules, e.g.\ \texttt{[ > Player | Crate ] -> [ > Player | > Crate ]}.
The engine evaluates the rule list in order at every tick, repeating
the block while \texttt{again} fires. State is a discrete multi-channel
grid, dynamics are deterministic and combinatorial, and the per-tick
computation is a sequence of atomic local updates.

We propose a \emph{rule-conditioned Neural Cellular Automaton} (NCA)
world model. A perceiver-style encoder maps the tokenized game spec to
$K$ latent slots; the dynamics body is a local update rule applied for
$T$ iterations on a hidden grid, cross-attending to those slots at
every step. Sharing body parameters across iterations mirrors the
engine's outer loop; the conditioner makes the dynamics portable across
games. Predicting the engine state directly (rather than pixels) lets
us measure fidelity cell-by-cell against the engine.

Our corpus contains 3{,}474 token-distinct human-authored games (1--20
rules each), with up to 199 used in the largest training preset. We
cache bounded-A* transitions from authored levels ($\approx 15$M
transitions); held-out evaluation uses a 30-game stratified sample
disjoint from training by name and token-sequence hash.

We make the following contributions:
\begin{enumerate}
  \item \textbf{NCA dynamics over discrete state.} A shared,
        iteratively-applied local update body, operating on the
        engine's native discrete grid, outperforms non-iterative
        baselines (CNN, U-Net, ViT) on rollout fidelity in a
        controlled comparison that varies only the spatial body.
  \item \textbf{Rule-conditioning for multi-game simulation.}
        A single set of weights simulates many games by
        cross-attending to slot embeddings of each game's tokenized
        rule text.
  \item \textbf{An evaluation protocol for unseen-rule generalization.}
        We construct \textsc{Heldout-30}, a 30-game stratified set
        disjoint from every training preset by filename and by
        token-sequence hash, and report against an identity baseline
        that lower-bounds the per-step state-change rate.
\end{enumerate}
