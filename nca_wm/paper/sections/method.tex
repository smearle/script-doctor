\section{Method}
\label{sec:method}

\subsection{Problem setup}

A PuzzleScript game is a tuple $(\mathcal{O}, R, \{L_i\})$ of object
kinds, rewrite rules, and authored levels. Each level is a
multi-channel grid $s \in \{0,1\}^{C \times H \times W}$ with
$C = |\mathcal{O}|$ and channel $c$ indicating object kind $c$. An
action $a \in \{\texttt{up}, \texttt{down}, \texttt{left}, \texttt{right},
\texttt{action}\}$ and current state $s_t$ deterministically yield
$s_{t+1}$ via the engine; the state also carries a terminal \emph{won}
bit triggered by certain rules.

We train $f_\theta(s_t, a_t, g) \mapsto \widehat{s}_{t+1}$ where $g$
is a latent representation of the game's symbolic source. We obtain
$g$ from the tokenized game source (integers from a $\approx
140$-symbol vocabulary covering the engine grammar, per-game object
names, and 5$\times$5 sprite RGBA values when sprite tokens are
enabled). At evaluation we roll the model out autoregressively and
compare cell-by-cell against the engine.

\subsection{Rule-conditioned NCA world model}

$\mathrm{Enc}_\phi$ maps the token sequence $\mathrm{spec} \in \mathbb{Z}^{S}$ (or the corresponding autoencoder latent) to slots $z \in \mathbb{R}^{K \times d}$ via $\ell$ self-attention layers followed by $K$ learned query vectors cross-attending into the contextualised tokens.
Slots are shared across cells and fixed for the rollout.

A single dense layer embeds the per-cell concatenation of $s_t$ and the broadcast one-hot action into $h^{(0)} \in \mathbb{R}^{H \times W \times d_h}$, after which we apply $T$ NCA steps:
\begin{align}
  h^{(k+1)} &= h^{(k)} + W_o \,\mathrm{GELU}\!\bigl(
      W_c\, [\, h^{(k)} \,;\, h^{(0)} \,]_{3\times 3}
      \;+\;
      \mathrm{XAttn}(h^{(k)}, z)
    \bigr) \, ,
\end{align}
where $[\,\cdot\,]_{3\times 3}$ is a $3{\times}3$ convolution per cell, $\mathrm{XAttn}$ is multi-head attention with each cell as a query and the $K$ slots as keys/values, and $W_o, W_c$ are shared across all $T$ steps.
The \emph{input-skip} concatenation re-injects the embedded $(s_t, a_t)$ at every step to keep the unroll anchored to its input.
Since PuzzleScript has two natural iteration levels (an inner ordered rule list, an outer \texttt{again} re-evaluation loop), we factor $T = n_\ell \cdot n_r$ with $n_\ell$ distinct inner layers and $n_r$ shared-weight outer passes; $n_r = T$ recovers a single shared layer applied $T$ times, while $n_r = 1$ recovers a per-step body with $T$ distinct layers.

A $3{\times}3$ convolution propagates one cell of context per step, but several PuzzleScript patterns reference cells arbitrarily far apart (\texttt{[ X | ... | Y ]} or \texttt{[X][Y]}).
We therefore augment each step with three optional pool stacks computed from $h^{(k)}$ and broadcast back per cell: axis max-pool (row+col), axis cumulative max (directional prefix-max in four directions), and global max-pool---surfacing non-local information that would otherwise require $\Omega(\max(H,W))$ NCA steps to reach.

A shared \texttt{readout} dense maps $h^{(T)}$ cell-wise to next-state logits $\widehat{s}_{t+1}$, and a separate dense over spatially average-pooled $h^{(T)}$ produces a binary win logit.
Training loss is $\mathcal{L} = \mathcal{L}_{\text{state}}(\widehat{s}_{t+1}, s_{t+1}) + \alpha\,\mathcal{L}_{\text{win}}$, where $\mathcal{L}_{\text{state}}$ is per-cell BCE upweighting cells that change between $s_t$ and $s_{t+1}$ and $\mathcal{L}_{\text{win}}$ is binary cross-entropy on the win head.

\subsection{Baselines}

Three non-NCA baselines share the encoder, input embedding, and
readout heads, replacing only the NCA body so the comparison
isolates the spatial-update body. The \textbf{CNN} stacks $n_b$
residual blocks (conv + optional pool + slot-cross-attn + residual
gate) with \emph{distinct} per-block weights, testing whether
iteration with weight sharing matters at all. The \textbf{U-Net}
is a 2-level encoder-decoder with skip connections and a FiLM
bottleneck that reads pooled slots, testing whether multi-scale
hierarchy substitutes for repeated local updates. The \textbf{ViT}
stacks $n_v$ Transformer encoder layers over flattened cells with
learned 2D positional embeddings plus per-layer slot cross-attention,
testing whether unrestricted global attention beats locality plus
iteration. All baselines accept $(s_t, a_t, g)$ and produce the same
$(\widehat{s}_{t+1}, \widehat{w}_{t+1})$ outputs.
